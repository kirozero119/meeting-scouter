> その会議、地に足はついていましたか？

「認識をアラインしましょう」「温度感を見ながら」「一旦持ち帰ります」「詳細は次回改めて」——
今日もどこかの会議室で、誰も着地しない言葉が飛び交っています。

**会議スカウター**は、議事録を読み込んで会議の「空中戦指数」を診断する Agent Skill です。
横文字・曖昧表現・未決定・責任の所在を検出し、その会議がどれだけ空を飛んでいたかを数値で言い渡します。

```text
╭────────────────────────────────────────────────────────────╮
│                  会議スカウター                            │
│          この会議、本当に必要でしたか？                    │
│                                                            │
│  ── 診断 ─────────────────────────────────────             │
│  全員の目線は揃いましたが、担当者と締切だけ別の会議に参    │
│  加しています。                                            │
│                                                            │
│  解析対象    weekly-meeting.md                             │
│  文字数      247文字                                       │
│  会議時間    60分 × 8名 = 延べ8.0時間                      │
│                                                            │
│  空中戦指数   87/100  █████████████████████░░░             │
│  ランク      S  — 地上との通信が途絶えています             │
│  会議戦闘力  9,700 — 高いほど空中戦です                    │
│              （当スカウター基準4,000の約2.4倍）            │
│  推定被害    延べ7.0時間が空中に消えました                 │
│  決定ペース  60分間で決定0件                               │
│                                                            │
│  ── 内訳 ─────────────────────────────────────             │
│  横文字               12回                                 │
│  曖昧・責任ぼかし      9回                                 │
│  決定事項              0件                                 │
│  アクション            2件                                 │
│  担当者不明            2件                                 │
│  期限不明              1件                                 │
╰────────────────────────────────────────────────────────────╯
```

60分 × 8名、決定0件。**延べ7時間——ほぼ1人の1営業日ぶんの労働が、空中に消えました。**

Claude Code と Codex で動きます。議事録のコピペでも、ローカルのファイルパスでもOKです。

## 30秒で試す

```bash
git clone https://github.com/kirozero119/meeting-scouter.git
cd meeting-scouter
./install.sh --all
```

あとはエージェントに議事録を渡すだけ:

```text
/meeting-scouter ./docs/weekly-meeting.md      # Claude Code
$meeting-scouter ./docs/weekly-meeting.md      # Codex
```

貼り付けでも動きます:

```text
/meeting-scouter
本日のアジェンダですが、まず関係者と認識をアラインして……
```

自然文でも呼べます:

```text
この議事録を会議スカウターで診断して: ./meeting-notes.txt
```

## 何を測っているのか

空中戦指数（0–100）は4軸の合計です。

| 軸 | 配点 | 検出するもの |
|---|---:|---|
| 横文字 | 0–25 | アジェンダ、アライン、フィックス……既知の会議語＋AIが文脈から発見する新種 |
| 曖昧・責任ぼかし | 0–30 | 「温度感を見ながら」「関係各所と連携して」「一旦持ち帰ります」 |
| 未決定 | 0–20 | 決定の少なさ。3時間で決定1件は、30分で決定1件より重症 |
| 責任不明 | 0–25 | 担当者と期限がこの世界に存在しないアクション |

会議時間と出席人数を教えると、診断はさらに現実に近づきます。

- **時間あたり密度**: 同じ横文字10連発でも、30分会議なら濃厚な空中戦、3時間会議なら希釈。決定の少なさも時間あたりで判定
- **推定被害**: 会議時間 × 出席人数 × 指数で「延べ何時間ぶんの労働が空中に消えたか」を算出。延べ8時間を超えると営業日換算も表示されます。2名のグダグダと8名のグダグダは、指数が同じでも被害が違います

### ランク

| 空中戦指数 | ランク | 診断 |
|---:|:---:|---|
| 0–19 | 健全 | 仕事が進んでいます |
| 20–39 | C | 少し足元が浮いています |
| 40–59 | B | 会議らしくフワついています |
| 60–79 | A | かなり空中です |
| 80–94 | S | 地上との通信が途絶えています |
| 95–100 | SSS | 会議そのものが目的です |

会議戦闘力の「当スカウター基準4,000の約○倍」は、実測統計ではなく**演出用の架空基準**です。数値が高すぎてスカウターが弾け飛んだ場合の補償はいたしかねます。

## 特徴

- **入力は本文でもファイルパスでも**: Markdown、テキスト、PDF、DOCXなど、利用中のエージェントが読める形式に対応
- **固定辞書＋意味判定のハイブリッド**: 既知の会議語は決定論的に数え、未知の曖昧表現はAIが文脈から発見。スコア計算は同梱の Python エンジンが行うので再現性があります
- **育つ候補辞書**: あなたの現場特有の「新種会議語」を `~/.meeting-scouter/` に蓄積。議事録本文は保存しません
- **依存パッケージゼロ**: Python 3.10以上の標準ライブラリだけで動作
- **愛あるツッコミ**: 診断はあくまで会議の構造へ。特定の個人は攻撃しません

## インストール詳細

個別に入れる場合:

```bash
./install.sh --claude       # ~/.claude/skills/meeting-scouter
./install.sh --codex        # ~/.agents/skills/meeting-scouter
./install.sh --codex-legacy # ~/.codex/skills/meeting-scouter
```

既存インストールを上書きする場合は `--force` を付けます。

Codex の skill-installer からも入れられます:

```text
$skill-installer install https://github.com/kirozero119/meeting-scouter/tree/main/meeting-scouter
```

インストール後、必要に応じてCodexを再起動してください。

## 新語学習とプライバシー

AIが未知の曖昧表現を見つけると、次の情報だけを `~/.meeting-scouter/` に保存します。

- 発見した短いフレーズ
- カテゴリ、出現回数、平均信頼度
- 元文書を復元できない短いSHA-256フィンガープリント
- ソースラベル

議事録本文は保存しません。学習を止めたい場合は、スキルの実行コマンドに `--no-learn` を付けるようエージェントへ指示できます。保存先は `MEETING_SCOUTER_HOME` で変更できます。

候補一覧:

```bash
python3 meeting-scouter/scripts/meeting_scouter.py candidates
```
